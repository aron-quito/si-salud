============================================================
  PASO 1: Ejecutar la Base de Datos en MySQL Workbench
============================================================

  1. Abrir MySQL Workbench
  2. Conectarse al servidor MySQL local (localhost:3306)
  3. Ir a: File > Open SQL Script...
  4. Seleccionar: 01_Base_de_Datos_MySQL/si_salud_database_completa.sql
  5. Pulsar: Ctrl+Shift+Enter  (Ejecutar Script Completo)
  6. Verificar en el panel de mensajes que no hay errores
  7. En el panel izquierdo (Schemas) debe aparecer la base "si_salud"
     con 16 tablas listadas.

  VERIFICACIÓN RÁPIDA (ejecutar en una nueva pestaña):
  ─────────────────────────────────────────────────────
    USE si_salud;
    SHOW TABLES;                       -- Debe listar 16 tablas
    SELECT COUNT(*) FROM USUARIO;      -- Debe retornar 10
    SELECT COUNT(*) FROM BLOQUE_HORARIO; -- Debe retornar 32
    SELECT fn_calcular_edad('1990-03-15');  -- Debe retornar 36 (aprox)
    SELECT fn_verificar_slot_libre(1);     -- Debe retornar 1 (TRUE)

============================================================
  ARQUITECTURA TÉCNICA (para preguntas del docente)
============================================================

  Motor BD:      MySQL 8.x con ENGINE=InnoDB (soporte ACID + FK)
  Integridad:    Transacciones ACID en sp_registrar_cita_medica
  Concurrencia:  SELECT ... FOR UPDATE (bloqueo pesimista)
                 Previene doble-booking en slots simultáneos
  Anti-abuso:    Contador en HISTORIAL_REPROGRAMACION (máx 3)
                 Auto-bloqueo de USUARIO al exceder el límite
  Normalización: 3FN — tablas pivote (MEDICO_ESPECIALIDAD),
                 separación usuario/paciente/médico
  Frontend:      HTML5 + CSS3 (16 pantallas, design system propio)
